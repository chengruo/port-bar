PortBar v1.1.0 新增本地 CLI 与配套 AI Skill，让用户的本地 AI 可以管理主机、端口映射和 SSH 隧道。

## 新增

- CLI 支持主机和映射的增删改查、隧道启停、状态查询、日志和诊断。
- 提供 JSON 输出、稳定错误码、`--wait` 等待连接结果、`--dry-run` 预检查和 `--if-revision` 配置版本保护。
- 设置页新增“AI 与 CLI 自动化”，支持只读、隧道控制和配置编辑权限，以及 CLI、Skill 安装入口。CLI 权限默认关闭。
- 配套 `portbar` Skill 随应用打包，也可通过 `portbar skill install --directory PATH` 安装。
- CLI 与界面共用运行中的应用实例。查询不会自动启动应用，CLI 不提供密码读取或任意远程命令执行能力。

## 修复与改进

- 重复启动已连接隧道不再重建连接；停止时会取消待执行的自动重连。
- 多端口映射检查全部本地监听端口，监听超时会报告错误。
- 修复 SSH 进程退出回调与配置编辑之间的时序问题，并防止多个应用实例替换 CLI socket。
- 配置成功写盘后才报告保存成功，新保存的配置文件权限为 0600。
- 增加密码脱敏、配置保存失败提示，以及界面旧草稿与 CLI 更新之间的冲突保护。

## 使用方式

安装后打开 PortBar 管理窗口，在设置的“AI 与 CLI 自动化”中启用需要的权限。使用“安装 CLI…”将命令链接到 PATH 中的目录，使用“安装 AI Skill…”选择 AI 客户端的 skills 目录。

也可以直接运行：

```bash
/Applications/PortBar.app/Contents/Helpers/portbar --help
```

CLI 权限适用于同一 macOS 用户的本地程序。`connected` 表示本地监听就绪，远端应用健康需要另外验证。修改运行中的配置前需要先停止相关隧道。

## 验证

应用构建、现有模型与认证桥接测试，以及 CLI 跨进程集成测试通过。新增测试使用临时配置和本机模拟 SSH，不连接真实服务器或修改用户配置。
